# Graphicon 用户使用手册

> **适用版本：** Graphicon `0.3.0` 及以上。本文档描述仓库当前实现的浏览器端专业矢量编辑工作区、路径几何、AI 能力与实时协作。

Graphicon 是一款以画布为中心的图形编辑器。它适合制作图标、徽标、简单插画、社交媒体视觉稿和可编辑矢量草图。编辑器的本地画布、路径、图层、导出和项目文件功能可以直接使用；实时协作和 AI 功能需要通过本地或已部署的服务启动。

## 开始使用

### 运行方式

Graphicon 有两种运行方式。若只需要本地绘制、编辑、项目保存和导出，可直接用现代浏览器打开 `index.html`。如果需要 AI SVG、文生图、AI 排版或多人实时协作，请使用 Node.js 服务。服务会把密钥保留在服务端环境变量中，因此浏览器和 `.graphicon` 项目文件均不会保存 API 密钥。

| 使用场景 | 推荐方式 | 可用能力 |
| --- | --- | --- |
| 无网络草图或单人基础编辑 | 直接打开 `index.html` | 画布、图层、路径、布尔运算、本地快速排列、项目文件和本地导出。 |
| AI 生成、AI 排版或实时协作 | 安装依赖并启动服务 | 包含上述能力，以及同源 AI 请求代理与 WebSocket 协作房间。 |

### 服务启动步骤

请使用 Node.js 18 或更高版本，并建议使用 `pnpm`。在仓库根目录执行：

```bash
pnpm install
cp .env.example .env
# 可选：编辑 .env，按需填写 AI 相关变量
set -a && source .env && set +a
pnpm start
```

随后访问 `http://localhost:4173`。没有配置 AI 密钥时，编辑器不会受影响；AI 按钮会给出可读的配置提示，本地快速排列和协作仍可按各自条件使用。

> **提示：** `index.html` 引用 Fabric.js、Paper.js、Font Awesome 和 Inter 的公共资源。首次加载需要网络。如果部署环境需要完全离线，请将这些依赖替换为受控的本地副本。

### 创建第一个设计

首次进入画布后，建议先设置画布尺寸，再添加元素。右侧“画布尺寸”面板可设置 `64–4096 px` 的宽度和高度。点击“新建”会清空当前画布，因此在执行前应先保存项目文件。

一个常用的开始流程如下：

1. 在右侧设置画布尺寸，例如 `1080 × 1080`。
2. 从左侧分类素材库点击图标，或通过“上传素材”导入 SVG 与图片。
3. 使用画布中心的选择框移动、缩放和旋转对象。
4. 通过右侧属性、对齐与图层面板精调布局。
5. 使用导出中心导出最终 PNG、JPG、WebP 或 SVG。

## 工作区说明

Graphicon 使用三栏工作区：左侧用于创建内容与接入服务，中间是画布，右侧用于精确编辑和管理图层。顶部浮动工具栏放置高频命令，底部状态条显示当前选择、图层数、画布尺寸与视图缩放。

| 区域 | 主要内容 | 推荐使用方式 |
| --- | --- | --- |
| 左侧侧栏 | 文字、上传、项目操作、AI、插件、协作和素材库 | 从这里添加内容、保存/打开项目、连接协作房间。 |
| 中间画布 | 选择、变换、钢笔路径、辅助线、网格和视图导航 | 用于直接操作对象和观察最终构图。 |
| 浮动工具栏 | 撤销/重做、删除、复制、路径、组合、层级和快速导出 | 用于高频快捷操作；大多数操作也有键盘快捷键。 |
| 右侧属性面板 | 尺寸、位置、画布、导出、对齐、智能排版、路径几何、颜色和图层 | 用于数值精调、批量布局和专业路径处理。 |

## 基础画布编辑

### 添加对象

Graphicon 支持添加文本、内置 SVG 图标、图片和外部 SVG。文本工具可输入内容、字号并选择粗体或斜体；内置素材库按类别提供基础形状、行业图标和常用符号；文件上传与拖放均可导入图片或 SVG。

添加对象后，单击可选中，拖动可移动，边角控制点可缩放，顶部控制点可旋转。多选时可使用 `Ctrl/Cmd + A` 选择所有可见且未锁定对象，也可以按住平台常用的多选键逐个选择对象。

### 精确属性

选中对象后，右侧“尺寸”和“位置与旋转”面板可输入精确数值。启用“保持比例”后，改变宽或高将保持对象纵横比。位置以画布坐标系计，旋转以角度计。

对图片与矢量对象，颜色面板会按对象类型显示相应控件。矢量对象可以调整填充和描边；图片可使用可用的色彩替换工具和插件滤镜。任何改变均会写入当前项目和本地历史记录。

### 吸附、辅助线与视图

“智能吸附”会在对象靠近画布中心、其他对象的边缘或中心时对齐。“显示对齐线”会把对齐关系显示为临时辅助线。底部“网格参考”可开关网格；网格不会包含在导出的图片或 SVG 中。

视图按钮支持缩小、放大、聚焦选区和重置视图。按住 `Space` 或 `Alt` 并拖动可平移画布；该操作只改变观看位置，不会改变设计对象的实际坐标。

## 图层与精准布局

### 图层工作台

右侧图层面板会按画布堆叠顺序列出用户对象。每一行显示对象名称，并提供选择、重命名、显示/隐藏、锁定/解锁和改变层级的操作。锁定对象不会被正常选择或移动，适合用于背景、参考线或已经确认的构图部分。

| 图层动作 | 作用 | 注意事项 |
| --- | --- | --- |
| 重命名 | 将对象改为可识别名称 | 建议对重要图层使用语义名称，例如“主标题”“品牌图标”。 |
| 显示/隐藏 | 临时隐藏对象 | 隐藏对象默认不参与可见对象导出。 |
| 锁定/解锁 | 防止对象被移动、缩放或选中 | 锁定状态会保存在项目文件中。 |
| 上移/下移 | 改变对象堆叠顺序 | 也可使用工具栏的置顶、置底命令进行大幅调整。 |

### 对齐、分布与统一尺寸

当选择多个对象时，可在“对齐与分布”面板选择参照系。参照系为“画布”时，对象相对于整个画布对齐；参照系为“选区边界”时，对象相对于当前多选范围对齐。

对齐按钮支持左、水平居中、右、顶端、垂直居中和底端。分布工具在至少三个对象时提供水平或垂直等距分布；统一尺寸工具将对象宽度或高度匹配到参考对象。批量操作会作为单个历史步骤保存，可一次撤销。

### 智能排版

“智能排版”包含两个入口。

| 操作 | 是否需要密钥 | 行为 |
| --- | --- | --- |
| 快速排列 | 否 | 使用确定性本地算法，将已选择对象排列为自适应网格、横向陈列或纵向陈列。未选择对象时，会处理所有可见且未锁定对象。 |
| AI 建议 | 是 | 发送对象的名称、类型、尺寸和画布尺寸，获取列数、间距与留白建议，然后在本地应用布局。 |

快速排列会在单次事务中完成，可以通过撤销立即恢复原构图。AI 建议不会上传图片像素、图层原始数据或项目文件；若服务未配置，则使用快速排列作为无需网络的替代方案。

## 路径与贝塞尔编辑

### 绘制钢笔路径

点击浮动工具栏的“钢笔路径”或按 `P` 进入路径模式。在画布中单击添加锚点；按住 `Shift` 单击会创建带初始控制柄的曲线节点。双击画布可完成开放路径；再次点击第一个锚点或使用“闭合路径”可完成闭合路径。

> 开放路径至少需要两个锚点。闭合路径通常更适合填充图形、徽标轮廓和布尔运算。

### 编辑节点

选中由钢笔创建的路径后，点击“节点与贝塞尔编辑”或按 `N`。白色圆点是锚点，蓝色圆点是控制柄。拖动锚点会移动轮廓并带动相连控制柄；拖动蓝色控制柄会改变曲线切线方向与曲率。

双击锚点或点击“切换曲线”可在直线节点和贝塞尔曲线节点之间切换。点击“删除节点”会删除当前选中的锚点，但路径至少保留两个节点。点击“完成编辑”或按 `Esc` 退出节点模式。

### 路径几何

Graphicon 将路径几何计算交给 Paper.js，而画布交互、对象管理和导出继续由 Fabric.js 处理。选择两个非位图矢量对象后，可在“路径几何”面板使用合并、相减、相交和排除。

| 命令 | 结果 | 典型场景 |
| --- | --- | --- |
| 合并 | 合成两个对象的总轮廓 | 合并重叠徽标部件。 |
| 相减 | 从第一个选中对象中减去第二个对象 | 制作镂空孔洞或月牙形。 |
| 相交 | 仅保留重叠区域 | 截取两个形状的共同区域。 |
| 排除 | 保留不重叠区域 | 形成对称差或特殊装饰图形。 |
| 简化路径 | 降低冗余节点数量 | 优化导入的复杂路径或手绘路径。 |
| 平滑曲线 | 生成连续贝塞尔轮廓 | 让折线或不均匀节点更自然。 |

布尔运算是显式操作，而不是拖动时的实时计算。对于节点数量极大的图形，请先使用“简化路径”，再执行布尔运算。含位图的对象不能参与路径布尔运算。

## 历史记录

Graphicon 的历史记录上限为 120 个画布快照。每个快照包含对象、图层元数据、画布尺寸、背景颜色和网格状态。新增、删除、属性修改、路径几何、AI 导入、快速排列和网格切换等动作都会自动记入历史。

工具栏中的撤销和重做按钮会在无可用步骤时禁用，左侧 AI 面板下方显示当前可撤销/可重做步数。批量动作如智能排版会被合并为单条历史记录。

| 操作 | 快捷键 | 说明 |
| --- | --- | --- |
| 撤销 | `Ctrl/Cmd + Z` | 撤销最近一次编辑事务。 |
| 重做 | `Ctrl/Cmd + Y` | 恢复最近撤销的事务。 |
| 重做（macOS 常用） | `Ctrl/Cmd + Shift + Z` | 与重做命令等效。 |

实时协作收到远端完整画布快照后，会以该状态建立新的本地历史基线。这可避免撤销操作回滚其他协作者的最新状态；因此协作过程中应将较大的编辑分段完成并及时沟通。

## AI 智能编辑

### 可编辑 SVG 生成

在“AI 矢量助手”文本框输入清晰的描述，例如“扁平风格的蓝绿色叶片徽标，圆角轮廓，透明背景”。选择“生成可编辑 SVG”，然后点击“生成 SVG”。系统调用已配置的 Chat Completions 兼容服务，请求一个安全、无脚本的 SVG，并作为可编辑对象导入画布。

生成后建议检查节点、填充和描边，并通过图层面板命名。生成的 SVG 可继续组合、换色、执行路径几何，并导出为 SVG 或位图。

### 文生图

选择“文生图”，设置尺寸，再输入描述。系统调用兼容 `POST /images/generations` 的服务，并将生成结果作为图片对象置于画布中心。文生图适合纹理、背景、概念草图和复杂插画，不会自动转换为可编辑路径。

文生图服务可返回 Base64 数据或 HTTPS 图片 URL。服务器会对结果执行格式、协议和大小检查，再交由浏览器画布加载。若图片服务没有配置独立密钥，系统会尝试使用 `AI_API_KEY`。

> **隐私边界：** 提示词会发送至你配置的 AI 服务。请不要在提示词中输入机密、个人身份信息或未经授权的第三方内容。Graphicon 不会把密钥写入页面、项目文件或浏览器请求头。

### AI 排版建议

AI 排版只传递可见、未锁定对象的名称、类型和尺寸，以及画布宽高。服务返回经过限制的 `mode`、`columns`、`gap` 与 `padding` 建议。实际对象移动始终在浏览器内完成，并记为一个可撤销事务。

## 实时协作

实时协作适合小团队共同编辑同一画布。在左侧“实时协作”面板输入房间号和显示名称，点击“加入”。所有协作者输入相同房间号即可进入同一个房间。

协作采用最后写入的完整画布快照同步方式。加入房间的用户会获取已有画布，后续的对象新增、删除和修改会被防抖后发送给其他成员。成员标签显示当前在线人员。

| 能力 | 当前行为 | 使用建议 |
| --- | --- | --- |
| 画布同步 | 完整快照、最后写入生效 | 避免两人同时拖动同一对象。 |
| 房间存储 | 单一服务进程内存 | 服务重启后房间内容会清空，应先保存项目文件。 |
| 成员状态 | 加入、离开和成员列表 | 用显示名称区分角色，例如“设计-小王”。 |
| 权限与版本 | 当前未提供 | 正式生产协作应配合外部认证、持久化和版本管理。 |

## 导出与项目文件

### 项目文件

“保存”会下载 `.graphicon` 文件。该文件是 JSON 项目格式，保存画布尺寸、网格、图层元数据和可编辑对象，用于继续编辑。通过“打开”重新载入项目文件。

`.graphicon` 不是发布格式。请将它视为源文件，并在分享给他人前确认其中不包含不应共享的设计内容。

### 导出中心

导出中心按所有可见对象的边界加留白裁切，而不是固定导出整个画布。网格、辅助线和节点控制柄不会导出。

| 格式 | 背景 | 推荐用途 |
| --- | --- | --- |
| PNG | 透明 | 图标、界面资源、需要透明背景的图形。 |
| JPG | 白色 | 图片预览、轻量分享或不需要透明度的成品。 |
| WebP | 透明 | 网页资源与较小文件体积的场景。 |
| SVG | 矢量 | 徽标、图标、后续矢量编辑和高分辨率印刷。 |
| Graphicon 项目 | 项目数据 | 后续继续编辑和备份。 |

PNG、JPG 与 WebP 可选择 `1×–4×` 倍率。较高倍率会生成更大的文件，并增加浏览器内存消耗。

## 建议工作流

### 制作一枚可编辑图标

先设置正方形画布，再从素材库添加基础形状或使用 AI SVG 生成初稿。通过图层面板命名部件，使用对齐工具把主形与装饰形定位。需要镂空效果时选择两个矢量对象，执行“相减”。最后导出 SVG，并保存 `.graphicon` 源文件。

### 制作一张社交媒体视觉稿

创建目标平台尺寸的画布，上传背景图片或用文生图生成概念背景。添加文本与品牌图标后，通过智能排版快速建立层级，再手工微调。锁定背景层，保存项目文件，最后导出 `2×` PNG 或 WebP。

### 小团队共同制作标志草案

先启动服务并建立一个简洁的房间号。由一名成员创建基础画布后，其他成员加入。团队应避免同时修改同一对象；每完成一个阶段，保存 `.graphicon` 文件作为检查点。最终由一名成员整理图层、执行路径布尔运算并导出 SVG。

## 常见问题与排查

| 问题 | 可能原因 | 解决方法 |
| --- | --- | --- |
| AI 按钮提示未配置密钥 | 未加载 `.env` 或缺少对应变量 | 检查 `AI_API_KEY`；文生图可另设 `AI_IMAGE_API_KEY`，然后重新启动服务。 |
| 直接打开 HTML 后 AI 或协作不可用 | 文件模式不能使用同源 API/WebSocket | 执行 `pnpm start` 后访问 `http://localhost:4173`。 |
| AI 图像无法载入 | 图像服务不兼容、返回格式异常或跨域资源不可用 | 使用兼容 Images API 的服务；检查服务日志和变量设置。 |
| 布尔运算失败 | 对象包含位图、未选中恰好两个矢量对象，或路径过于复杂 | 选择两个矢量对象；先简化路径；确认第一个对象是相减操作的被减对象。 |
| 撤销后协作画布变化不符合预期 | 收到了远端快照，历史已建立新基线 | 与协作者协调操作顺序，并使用项目文件建立阶段性备份。 |
| 导出的画面范围不符合预期 | 导出使用可见对象边界裁切 | 检查隐藏图层和对象位置；必要时添加边界框或调整对象间距。 |
| 画布加载后素材显示异常 | 公共 CDN 不可达或网络受限 | 检查网络，或在部署时把第三方资源改为本地托管。 |
